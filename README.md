# TG Stats

Локальний аналізатор переписки Telegram. Завантажуй `result.json` — отримуй статистику.

## Можливості

- Загальна статистика: повідомлення, дні, слова, медіа
- Активність: теплова карта, по годинах та днях тижня
- Учасники: картки з медіаною відповіді, частотою, символами
- Контент: топ-40 слів (з фільтрацією шуму), топ емодзі, розподіл довжин
- Рекорди: серії, рекордні дні, найдовші повідомлення, тривалість голосових/кружечків
- Дзвінки: завершені, пропущені, зайнято, перервані, загальний час
- Підтримка "Нотатки" (saved messages / чат з собою)
- Поділитися статистикою (вибір секцій, приховування імен)
- Приховування/перейменування контактів у картках
- Фільтрація шумових слів (URL, хаха, мгм і т.д.)
- Мобайл-фьорст адаптивний дизайн

## Запуск локально

Потрібен будь-який статичний сервер (через ES modules не можна відкривати через `file://`).

```bash
# Python
python -m http.server 3000

# Node (без залежностей)
npx serve .

# або VS Code Live Server
```

Відкрий http://localhost:3000

2. Settings → Pages → Source: `main` / `root`

## Як отримати result.json

1. Відкрий **Telegram Desktop** (не мобільний)
2. Зайди в потрібний чат
3. Три крапки (⋯) → **Export Chat History**
4. Формат: **JSON** — медіа завантажувати не обов'язково
5. Знайди `result.json` у папці експорту

> Повний експорт акаунту: Налаштування → Конфіденційність → Експорт даних → JSON. Завантажуй тільки `result.json`, медіапапки не потрібні.

## Примітки

- Всі дані обробляються **локально у браузері**, нічого не відправляється на сервер
- Підтримуються особисті чати; групи підтримуються частково (без статистики дзвінків)
- Швидкість відповіді рахується лише якщо між повідомленнями було ≥30 хвилин мовчання
