# TGStats — Telegram Chat Analyzer

Красивий аналізатор переписки з Telegram. Завантажуєш `result.json` — отримуєш повну статистику.

## 🚀 Деплой

### Netlify (найшвидший варіант)
1. Зайди на [netlify.com](https://netlify.com) → "Add new site" → "Deploy manually"
2. Перетягни **цю папку** (`tgstats/`) у вікно деплою
3. Готово — отримаєш посилання типу `https://amazing-name-123.netlify.app`

### Vercel
```bash
npm i -g vercel
cd tgstats
vercel --prod
```

### GitHub Pages
1. Створи репозиторій на GitHub
2. Завантаж файли з цієї папки
3. Settings → Pages → Source: main branch / root
4. Через хвилину сайт буде на `https://username.github.io/repo-name`

## 📋 Як отримати result.json

1. Відкрий **Telegram Desktop** (не мобільний)
2. Зайди у потрібний чат
3. Три крапки (⋯) → **Export Chat History**
4. Формат: **JSON**
5. Вибери що включити: фото, стікери, голосові тощо
6. Натисни Export — завантажиться архів
7. Знайди в ньому `result.json` і завантаж на сайт

## 📊 Що аналізує сайт

- **Огляд**: 12 ключових метрик, графік по місяцях, розподіл між учасниками, типи медіа
- **Активність**: теплова карта (день × година), активність по днях тижня та годинах, динаміка переписки
- **Учасники**: картки кожного учасника з їхньою статистикою, середня довжина повідомлень, стековий графік
- **Контент**: топ-40 слів (хмара), топ-20 емодзі, розподіл довжин повідомлень, медіа по місяцях
- **Рекорди**: найактивніший день, найдовша серія, найдовше повідомлення, топ-10 активних днів

## 🔒 Приватність

Всі дані обробляються **локально у браузері**. Нічого не відправляється на сервер.
